# Evidencija rada — ES ENERGOSERVIS

Interaktivna dnevna evidencija rada (Daily Work Log). Otvara se u svakom
pregledaču (radi i na telefonu), popunjava se klikom i štampa u čist A4 PDF.

## Sadržaj
- `index.html` — digitalni obrazac (klik na gradilište, auto-sati, potpis, čuvanje, štampa/PDF)
- `Evidencija-rada-RUCNI-template.pdf` — blanko obrazac za ručno popunjavanje (za štampu)
- `evidencija-rucni-template.html` — izvor blanko obrasca

## Živi link (posle objavljivanja na GitHub Pages)
https://TVOJ-KORISNICKI-NALOG.github.io/IME-REPOZITORIJUMA/

## Kako se koristi (digitalni obrazac)
1. Otvori link, proveri datum i upiši odgovornog (supervizora).
2. Za svakog radnika klikni gradilište: Vršac / Sremska Rača / Radionica.
3. Upiši početak i završetak — sati se računaju sami.
4. Radnik se potpiše; dole opiši izvršene radove.
5. „Sačuvaj" (lokalno na uređaju) pa „Štampaj / PDF" → „Sačuvaj kao PDF" (A4).

> Pri štampi isključi „Headers and footers / Zaglavlja i podnožja" za potpuno čist PDF.
