# Evidencija rada — ES ENERGOSERVIS

Interaktivna **dnevna evidencija rada** (Daily Work Log) za ES ENERGOSERVIS.
Otvara se u svakom pregledaču (radi i na telefonu), popunjava se klikom i štampa u čist **A4 PDF**.

## 🔗 Živi link
**https://labranka.github.io/evidencija-rada/**

## Mogućnosti
- Klik na gradilište po radniku: **Vršac / Sremska Rača / Radionica**
- Automatsko računanje sati iz početka i završetka
- Potpis u polju (prst na telefonu ili miš), opis izvršenih radova
- **Dodavanje i uklanjanje** radnika (redova) na klik
- Raspored po gradilištu + ukupno sati (prikazuje se i u PDF-u)
- **Sačuvaj** (lokalno na uređaju) i **Štampaj / PDF** (A4)

## Kako se koristi
1. Otvori link.
2. Proveri datum i upiši glavnog/odgovornog (supervizora).
3. Za svakog radnika izaberi gradilište, unesi početak/završetak, potpis.
4. Dole opiši izvršene radove.
5. **Sačuvaj**, pa **Štampaj / PDF → „Sačuvaj kao PDF"**.

> Uneti podaci ostaju **lokalno u pregledaču** (localStorage) i ne šalju se nigde —
> trajna kopija je PDF koji sami napravite.
> Pri štampi isključite „Headers and footers / Zaglavlja i podnožja" u dijalogu za štampu
> da nestane datum/URL koji pregledač sam dodaje.
