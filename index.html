EVIDENCIJA RADA / DAILY WORK LOG

Dnevni izveštaj o prisustvu na radu / Daily Attendance Report

? Kako se koristi / How to use ▾
  1. 1Datum i odgovorni: datum je već postavljen na danas — upiši glavnog/odgovornog (supervizora). / Check the date and enter the supervisor.
  2. 2Gradilište: za svakog radnika klikni jedno — Vršac, Sremska Rača ili Radionica (oboji se crveno; ponovni klik poništava). / Click one site per worker.
  3. 3Sati: upiši Početak i Završetak — kolona „Sati" se popunjava sama. / Enter start & end; hours auto-calculate.
  4. 4Potpis: radnik se potpiše u polju — prstom na telefonu/tabletu ili mišem. / The worker signs in the box.
  5. 5Radovi: dole u polju opiši izvršene radove. / Describe the work done below.
  6. ＋Dodaj/ukloni radnika: dugme „Dodaj radnika" dodaje novi red; × pored rednog broja uklanja red. / Add a worker, or remove a row with ×.
  7. 6Sačuvaj / Štampaj: Sačuvaj preuzme backup fajl na uređaj (vraćaš ga preko Učitaj); za gotov dokument klikni Štampaj / PDF → „Sačuvaj kao PDF" (A4). / Save downloads a backup; Print → Save as PDF for the final A4.
